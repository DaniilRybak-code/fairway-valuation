# data/raw

**Original files, exactly as they arrived. Never edited, never cleaned, never deleted.**

Anything derived from a file here goes in `data/`, not here. When a number is ever disputed, this
folder is what settles it.

Naming: `YYYY-MM-DD_what-it-is.csv`, for example `2026-08-30_capiq-listed-logistics.csv`.

If a file here has no matching row in `data/MANIFEST.md`, the manifest is wrong. Fix the manifest.
